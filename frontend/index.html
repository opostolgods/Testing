Туториалы

Пошаговые инструкции по настройке VPN на всех платформах

Android — V2RayNG

~2 мин
  1. Установите V2RayNG из Google Play
  2. В личном кабинете CloudVPN нажмите «Копировать ключ»
  3. Откройте V2RayNG → нажмите + → «Импорт из буфера обмена»
  4. Нажмите кнопку ▶ внизу экрана для подключения
  5. Разрешите VPN-соединение при запросе системы
Совет: Вы также можете нажать кнопку «Открыть в V2RayNG» в личном кабинете для автоматического импорта.

iOS — Streisand

~2 мин
  1. Установите Streisand из App Store
  2. В личном кабинете CloudVPN скопируйте ваш VLESS ключ
  3. Откройте Streisand → + → «Добавить из буфера»
  4. Включите VPN переключателем на главном экране

iOS — Happ

~2 мин
  1. Установите Happ из App Store
  2. Скопируйте VLESS ключ из личного кабинета
  3. В Happ нажмите «Добавить сервер» → «Из буфера»
  4. Подключитесь одним нажатием

Windows / Linux — Nekoray

~3 мин
  1. Скачайте Nekoray с GitHub
  2. Распакуйте архив и запустите nekoray.exe
  3. Скопируйте VLESS ключ из личного кабинета
  4. В Nekoray: Сервер → «Добавить профиль из буфера»
  5. Кликните правой кнопкой на сервер → «Запустить»
  6. Включите «Системный прокси» или «TUN режим»

Обновление конфигурации

~1 мин
  1. Если VPN перестал работать, зайдите в личный кабинет
  2. Удалите старый ключ и создайте новый
  3. Импортируйте новый ключ в приложение
  4. Если проблема сохраняется — напишите в поддержку
Важно: При обновлении конфигурации сначала удалите старый профиль из VPN-приложения, затем добавьте новый.

Частые вопросы

VPN не подключается, что делать?
Попробуйте создать новый ключ в личном кабинете и заново импортировать его в приложение. Если не помогло — напишите в поддержку.
Какая скорость у VPN?
VLESS + Reality обеспечивает минимальные потери скорости. Обычно 80-95% от вашей обычной скорости интернета.
Чем Free отличается от Premium?
Premium дает доступ к 2 серверам, 5 ключей, 3 устройства на ключ и приоритетную поддержку. Free — 1 ключ, 1 устройство, 1 сервер.
